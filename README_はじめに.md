# Word Boost — iPhoneホーム画面に追加できるWebアプリ

これは**SwiftUIネイティブiOSアプリではなく**、GitHub Pagesで公開してiPhoneのSafariからホーム画面に追加できるWebアプリ（PWA）です。

## できること
- 500語のビジネス英単語を収録（600点向け263語、730点向け137語、860点向け100語）
- 目標帯は600/730/860点から選択（上位帯を選択すると下位帯も学習対象）
- 今日のミッション（新規最大10語、期限到来の復習最大10語、合計最大15語）
- フラッシュカード、3段階の復習、4択テスト
- 自分で英単語を追加、苦手一覧、お気に入り、学習記録
- 端末内に学習履歴を保存（ネット同期なし）
- 音声読み上げ（対応ブラウザ上、端末の音声合成機能を使用）
- アイコン、ホーム画面への追加、初回の読み込み・キャッシュ後のオフライン利用（一部端末条件による）

## GitHub Pagesで公開する方法
1. このZIPを解凍します。
2. GitHubのリポジトリを開き、ファイルをアップロードします。**ZIPファイルそのものではなく、解凍後の `index.html`、`app.js`、`styles.css`、`manifest.webmanifest`、`sw.js`、`assets/`、`data/` をまとめてリポジトリの最上位に置いてください。**
3. GitHubのリポジトリの **Settings → Pages** を開きます。
4. **Build and deployment → Source: Deploy from a branch** を選び、**Branch: main / (root)** を選択して保存します。
5. Pagesの画面に出る公開URL（例：`https://ユーザー名.github.io/リポジトリ名/`）を開きます。**github.comのファイル一覧は学習アプリのURLではありません。**
6. iPhoneの **Safari** で公開URLを開き、**共有 → ホーム画面に追加 → 追加** と進むと、Word Boostのアイコンが表示されます。Safariのバージョンによって項目の位置や名称が少し異なります。

> GitHub Pagesで公開する際に、リポジトリや公開内容の公開範囲を確認してください。JSON中の単語データは公開されます。ユーザーの学習履歴はWebサイトへアップロードせず、閲覧端末のブラウザ内に保存されます。

## ローカルPCでの動作確認
解凍先のディレクトリで `python3 -m http.server 8000` を実行し、ブラウザで `http://localhost:8000` を開きます。
ファイル一覧から `index.html` をそのまま開くと、ブラウザのセキュリティ制約によりJSONの読み込みに失敗することがあります。

## フォルダ構成
```text
index.html                Webアプリの入口
app.js                    学習画面、SRS、テスト、履歴
styles.css                デザイン（ダークモード対応）
manifest.webmanifest      ホーム画面登録用の設定
sw.js                     オフラインキャッシュ
data/words_600.json       600点帯の263語
    words_730.json        730点帯の137語
    words_860.json        860点帯の100語
assets/icon-180.png       iPhoneホーム画面アイコン
       icon-192.png       PWA用
       icon-512.png       PWA用
       icon-1024.png      将来のネイティブアプリアイコン用
```

## 制約・注意
- iOSのネイティブアプリ（SwiftUI/SwiftData）ではありません。後でXcodeアプリに移植する場合は別途実装が必要です。
- 学習記録は `localStorage` に保存します。ブラウザのデータ削除・端末変更・ストレージ制限により失われることがあります。iCloud同期・バックアップはありません。
- オフライン利用は初回のオンライン読み込みとService Workerの保存完了後に限ります。iOSのストレージ整理によりキャッシュが消えることがあります。音声合成がオフラインで機能するかは端末と音声データに依存します。
- リマインダー通知、ネイティブウィジェット、StoreKitの機能は未実装です。
- 日本語訳、例文、語彙の難易度区分は公開前の校閲が必要です。特定の試験団体の公式アプリではありません。
- 完璧：初回翌日、その後間隔を約2.5倍、あいまい：据え置き、忘れた：翌日。忘れた3回連続は例文付き特別復習の表示が出ます。

## ファイルの差し替え
単語パックを追加・更新する場合は `data/` 内のJSONを更新し、`sw.js` の `CACHE_NAME` を `wordboost-pwa-v2` のように変更してください。これで以前のキャッシュを更新しやすくなります。
